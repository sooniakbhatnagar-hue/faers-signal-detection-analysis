# FAERS Drug Safety Signal Detection

## Project Overview
This project analyzes FAERS adverse event data to identify potential drug safety signals using disproportionality metrics such as PRR and ROR.

## Tools Used
- Python
- Pandas
- Matplotlib
- Kaggle Notebook
- Power BI Desktop

## Analysis Performed
- Data cleaning
- Top reported drugs
- Adverse event analysis
- PRR/ROR signal detection
- Visualization of safety signals

## Dataset
FAERS Drug Event Signal Dataset

## Key Concepts
- Pharmacovigilance
- Signal Detection
- Aggregate Safety Analysis
- Drug-event association
